# LAB1
# ЛР 1. Формування сигналу з відповідними параметрами

## Мета
Навчитися налаштовувати порт вводу-виводу (GPIO) мікроконтролера STM32 і сформувати на виході сигнал із заданими параметрами (частота, тривалість імпульсу). Результат відображається миготінням світлодіода.

## Обладнання та ПЗ
- Плата STM32F411E-DISCO (STM32F411VET6)
- STM32CubeMX, STM32CubeIDE, бібліотека HAL
- Кабель USB (ST-LINK) для живлення й прошивки

## Теоретичні відомості
GPIO-вивід у режимі виходу push-pull може видавати логічний рівень 0 або 1. Якщо періодично змінювати рівень із певним інтервалом, на виході утворюється прямокутний сигнал. Його параметри:
- **період T** (с) і **частота f = 1/T** (Гц);
- **тривалість імпульсу** (час, коли рівень високий) і **коефіцієнт заповнення** (duty cycle).

Світлодіод, підключений до виводу, показує цей сигнал: при частоті в кілька герц видно окремі спалахи.

## Налаштування в CubeMX
Вивід [PD14] налаштовано як **GPIO_Output** (режим Output Push-Pull, без підтяжки).

## Алгоритм роботи
1. Ініціалізація HAL, тактування і GPIO.
2. У нескінченному циклі: увімкнути світлодіод → затримка → вимкнути світлодіод → затримка.

```c
while (1)
{
    HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, GPIO_PIN_SET);
    HAL_Delay(500);
    HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, GPIO_PIN_RESET);
    HAL_Delay(500);
}
```
